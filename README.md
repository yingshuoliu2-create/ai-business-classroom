# ai-business-classroom
刘盈铄 AI 实战讲师个人互动课堂网站

公开访问：https://yingshuoliu2-create.github.io/ai-business-classroom/

八章、十分钟的互动课堂，围绕 AI 概念、创新与营销、公司落地和持续订阅展开。

- 首页：可拖动旋转、点击关键词的 CSS 3D 价值模型。
- 概念页：例子切换、生活类比、概念小测与搜索词典。
- 行动页：四种工作方式比较，可填写、生成和复制任务指令模板。
- 公司页：数据分析、客户服务、营销内容三种流程演示，包含人工审核节点。
- 营销页：四步互动内容流程。
- 测算页：三组假设、实时耗时滑块和成本计算。
- 课堂工具：章节导航、演讲模式、十分钟计时、讲师备注、行动清单下载。

`index.html` 保留原始课堂主体，`classroom.css` 提供统一视觉样式，`classroom.js` 提供互动与课程笔记整合。无需构建步骤，可直接通过静态服务器运行。表单、演示与测算均在浏览器本地运行，无模型 API、账号数据或消息发送后端。

内容结合用户提供的 WorkBuddy 对话及 9 月 10 日两份学习笔记，重点参考下午课程中的生活化类比。原始附件不随站点发布。
